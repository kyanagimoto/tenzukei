# てんずけい

6歳前後の子ども向けに、点図形（点つなぎ）や立体図形（積み木の見取り図）の模写プリントを作るためのリポジトリです。左側の「おてほん」を見て、右側の方眼・点図の上に同じ図形を書き写す形式の問題を出力します。

## ファイル構成

- `generate_worksheets.sh` — 点図形・立体図形模写プリントを生成・編集するためのスクリプト。
- `generate_rotation_worksheets.sh` — 図形回転（図形倒し）プリントを自動生成するためのスクリプト。

## 使い方

### 1. 新しい問題プリントを生成する

点図形（星型などの多角形）と立体図形（積み木の見取り図）を組み合わせた新しいプリント（HTML、A4想定）を生成します。

```sh
sh generate_worksheets.sh --new-problem "生徒の名前" [問題数] [出力ファイル名]
```

- `問題数` — 省略時は6問（4問ごとに1ページ、2ページ構成になります）。
- `出力ファイル名` — 省略時は `new_problems.html`。

生成されたHTMLファイルをブラウザで開くと、そのまま印刷できます（1ページ = A4縦、問題を4マス配置）。

#### Option: 枚数（ページ数）を直接指定する

`問題数`（4問=1枚として計算する数字）の代わりに、`--sheets` オプションで「何枚のプリントを1つのHTMLにまとめるか」を直接指定できます。1枚 = 4問として自動計算されます。

```sh
sh generate_worksheets.sh --new-problem "生徒の名前" --sheets [枚数] [出力ファイル名]
```

例: 3枚（12問）分を1つのHTMLにまとめて生成する

```sh
sh generate_worksheets.sh --new-problem "たろう" --sheets 3
```

#### 立体図形の描き方について

立体図形は、単発のキューブを並べて描くのではなく、`(i, j, k)` の格子座標で積み木の集合（ポリキューブ）として定義し、隠れる面を奥から手前へ描く「画家アルゴリズム」で塗り分けています。これにより、立方体同士がきちんと繋がった自然な見取り図になり、辺は方眼線の交点にぴったり揃います。

### 2. 図形回転（図形倒し）プリントを生成する

指示されたマーク（▲：左に1回、△：左に2回、◆：右に1回、◇：右に2回倒す）に従って回転させた図形を、右側の4つの候補の中から選ぶプリント（HTML、A4横向き想定）を自動生成します。

```sh
sh generate_rotation_worksheets.sh "生徒の名前" [シート数] [出力ファイル名]
```

- `シート数` — 省略時は1シート（1シート = 5問、問題シート＋解答シートのペアで出力されます）。
- `出力ファイル名` — 省略時は `rotation_problems.html`。

#### Option: `--sheets` や `--problems` での指定

```sh
# 3シート（15問）分を生成
sh generate_rotation_worksheets.sh "りのすけ" 3

# オプション構文で指定
sh generate_rotation_worksheets.sh --sheets 3 "りのすけ"
sh generate_rotation_worksheets.sh --problems 10 "りのすけ"
```

#### 特徴

- **写真の実物教材を忠実再現**: A4横向き、上部の操作凡例（矢印・記号）、元の図形と選択肢を隔てる二重線など、実際の小学校受験ペーパー教材に合わせた精密なレイアウトです。
- **多様で美しい図形バリエーション**: 直角二等辺三角形、扇形・円弧、長方形分割、X字4分割（ちょうネクタイ・砂時計）、小ブロックL字など、多彩な幾何学パターンからランダムに非対称図形を生成します。
- **質の高いひっかけ（ダミー）候補**: 4つの選択肢には、正解1つのほかに「他の回転角度（回しすぎ・逆回転）」「左右反転（鏡像の勘違い）」「1パーツだけ向きが違うニアミス変形」など、よく観察しないと見分けがつかない良問ダミーが自動配置されます。
- **解答シート（丸付け用）同梱**: 問題シートの直後に、正解の図形に青丸印が付いた【こたえ】シートが自動生成されます。ブラウザ上部ツールバーから「問題のみ印刷」「解答のみ印刷」「全ページ印刷」をワンクリックで選択できます。

## GitHub Actions での PDF 生成

GitHub リポジトリの **Actions** タブから、ブラウザ上で直接 PDF を生成してダウンロードできます。

1. **点図形・立体図形プリントの PDF 生成**:
   - ワークフロー「**Generate PDF Worksheets**」を選択
   - 「Run workflow」をクリックし、生徒名とシート数を入力して実行
   - 完了後、Artifacts（成果物）から `worksheets-pdf` をダウンロード

2. **図形回転（図形倒し）プリントの PDF 生成**:
   - ワークフロー「**Generate Rotation PDF Worksheets**」を選択
   - 「Run workflow」をクリックし、シート数（1シート = 5問）や対象ページ（`all`: 問題＋解答、`problems`: 問題のみ、`answers`: 解答のみ）を指定して実行
   - 完了後、Artifacts（成果物）から `rotation-worksheets-pdf`（A4横向きPDF）をダウンロード

## 開発上の注意

- 出力はすべて日本語（ひらがな中心）で、対象年齢は6歳前後を想定しています。
- `student_name` に二重引用符や改行を含めることはできません（スクリプト側でチェックしています）。
